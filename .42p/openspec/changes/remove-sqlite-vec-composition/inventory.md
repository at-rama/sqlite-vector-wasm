## Reproducibility and licensing boundary

Distribution C-inputs requires clean reproduction of the defined current functionality, with pinned inputs/tools/options; it does not require byte-identical builds. W/C-reconciliation preserves historical contracts/evidence. S-retained-capability additionally requires present-day consumption of both engines; D1 explicitly proposes removing that obligation, not silently reinterpreting it. Until adoption, deleting old inputs/build support violates the current contract.

Historical reproduction remains addressable at each release's exact recorded source commit, where its old locks, notices and code are still available. This inspection establishes source availability in Git, not successful renewed reconstruction, external upstream availability or continued host/tool support. Do not copy that historical code into another current adapter. Published-archive reading and uniqueness/transition tests are retained because they serve the current Vector release contract. Old-only package notices can leave the current tree only once no current selected payload requires them; historical shipped notice bytes remain untouched.
